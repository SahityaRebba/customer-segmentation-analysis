# Customer Segmentation Analysis Dashboard

## 🎯 Project Overview
Customer segmentation analysis for e-commerce company to identify customer groups and provide targeted marketing recommendations.

## 📊 Features
- Customer segmentation (Platinum, Gold, Silver, At Risk, Bronze)
- Interactive filters (City, Category)
- Revenue analysis by category and city
- Age group analysis
- Customer 360° view

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## 🚀 How to Run

```bash
pip install streamlit pandas plotly
streamlit run customer_segmentation.py
